# Medical-Diagnosis-Center-by-Service-Portal-ServiceNow-


## Project Overview

Medical Diagnosis Center is a ServiceNow-based application developed using ServiceNow Service Portal to manage diagnostic test bookings and related patient services.

The application provides a centralized platform for managing patients, diagnostic tests, appointments, cancellations, refunds, and diagnostic reports. The Service Portal provides a user-friendly interface through which users can view available diagnostic tests, manage bookings, and access reports.

## Key Features

- Patient registration and management
- Diagnostic test management
- Diagnostic test selection
- Appointment booking and management
- Appointment cancellation
- Refund calculation for cancelled appointments
- Automatic report generation after appointment completion
- Diagnostic report management
- Service Portal access
- Administrative management of application records

## Main Tables

| Table | Purpose |
|---|---|
| Patient | Stores and manages patient information |
| Diagnostic Test | Stores available diagnostic tests and their details |
| Appointment | Manages patient appointments and booking information |
| Report | Stores and manages diagnostic reports |

## Service Portal

The project includes a customized ServiceNow Service Portal that provides users with access to the Medical Diagnosis Center services.

The portal provides functionality for:

- Viewing available diagnostic tests
- Managing bookings
- Accessing reports
- Interacting with appointment-related services

## Technologies Used

- ServiceNow
- ServiceNow Service Portal

- JavaScript
- ServiceNow Tables and Forms
- Business Rules and Automation

## Project Objectives

1. Provide a centralized system for managing diagnostic center activities.
2. Simplify patient and diagnostic test management.
3. Provide an organized appointment booking process.
4. Support appointment cancellation and refund calculation.
5. Automate report generation after appointment completion.
6. Provide users with a simple Service Portal interface.
7. Improve management of diagnostic reports and related records.
